# موسوعة الوضوء والغسل والتيمم في المذاهب الأربعة

جمع وإعداد: كليب بن أحمد بن ضيف الله الزهراني

## محتويات المجلد

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كاملًا |
| `mawsuat-altaharah.pdf` | «موسوعة الوضوء والغسل والتيمم في المذاهب الأربعة» كاملة للطباعة |
| `hukm-altalfiq.pdf` | «حكم التلفيق بين المذاهب: الصلاة نموذجًا» |
| `cover-mawsuat-altaharah.jpg` و`cover-hukm-altalfiq.jpg` | صورتا الغلافين في بطاقات الكتب |
| `manifest.webmanifest` و`icon-192.png` و`icon-512.png` و`apple-touch-icon.png` | أيقونة التطبيق عند إضافته إلى الشاشة الرئيسة في الجوال |
| `og-image.png` | الصورة التي تظهر عند إرسال رابط التطبيق في واتساب وتيليجرام وغيرهما |
| `.nojekyll` | ملف فارغ لإعدادات GitHub Pages، ولا يضر إن لم يُرفع |

لا تغيّر أسماء الملفات، فالتطبيق يستدعيها بأسمائها.

## النشر على GitHub Pages

1. ادخل إلى github.com بحسابك.
2. اضغط **New repository**، واكتب اسمًا إنجليزيًّا قصيرًا مثل `LearnTaharah4Emam`، واجعله **Public**، ثم **Create repository**.
3. في صفحة المستودع اضغط **uploading an existing file**، واسحب إليها ملفات هذا المجلد كلها، ثم اضغط **Commit changes**.
4. افتح **Settings**، ثم **Pages**. وفي **Source** اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
5. بعد دقيقة أو دقيقتين يصبح التطبيق على الرابط:
   `https://اسم-المستخدم.github.io/اسم-المستودع/`

## تحديث التطبيق لاحقًا

ارفع `index.html` الجديد بالطريقة نفسها، فيحل محل القديم، ويتحدث الموقع خلال دقائق. والعلامات والملاحظات المحفوظة عند القرّاء لا تضيع بالتحديث.

## التجربة بعد النشر

- **على آيفون (سفاري):**
  - افتح الرابط، واصنع بطاقة من أي فقرة، واضغط «مشاركة الصورة»، ثم اختر واتساب.
  - جرّب «إضافة إلى الشاشة الرئيسة» من زر المشاركة في سفاري.
- **على جالكسي (كروم أو سامسونج إنترنت):**
  - جرّب الخطوات نفسها.
  - تجد «إضافة إلى الشاشة الرئيسة» في قائمة المتصفح.
- **على الحاسوب:** افتح البطاقة، واضغط «نسخ الصورة»، ثم الصقها في واتساب ويب أو تيليجرام.
